# VLSI & Digital Design Lab

A collection of digital design, CMOS layout, and multiphysics simulation work completed as part of my Electrical and Electronics Engineering coursework at VIT Vellore.

## Projects

### 01. 4-bit Carry Look-Ahead Adder
**Tools:** Verilog HDL, Xilinx Vivado

Designed a 4-bit binary adder using generate and propagate logic to calculate carry signals. The lab work includes the RTL implementation, testbench, and simulation waveform.

**Concepts:** Combinational logic, carry generation, and propagation.

### 02. 4-bit Ripple Carry Adder
**Tools:** Verilog HDL, Xilinx Vivado

Implemented a 4-bit binary adder by cascading full-adder stages. The design was simulated to examine the addition and carry-propagation behavior.

**Concepts:** Modular RTL design, full-adder stages, and carry propagation.

### 03. 16 × 8 Synchronous RAM
**Tools:** Verilog HDL, Xilinx Vivado

Worked on a synchronous RAM design with 16 addressable locations, each storing 8 bits. The design uses clocked memory operations and a write-enable control signal.

**Concepts:** Memory arrays, address selection, read/write operations, and sequential logic.

### 04. CMOS Logic Gate Layouts
**Tools:** Magic VLSI, IRSIM, SCMOS technology

Designed layouts for six basic CMOS logic gates: NOT, NAND, OR, AND, NOR, and XOR. Performed Design Rule Check (DRC) and documented functional verification using IRSIM.

The lab report records zero DRC violations for the layouts.

**Concepts:** CMOS transistor-level layout, PMOS/NMOS networks, physical design rules, and layout verification.

### 05. Electrical and Thermal Simulation of VLSI Metal Interconnects
**Tools:** COMSOL Multiphysics 6.0

Modelled a two-layer nanoscale metal interconnect and analysed its electrical and thermal behaviour using multiphysics simulation.

The study examined electric potential distribution, electric field concentration, and temperature distribution associated with Joule heating near the interconnect junction.

**Concepts:** VLSI interconnects, electric fields, current crowding, thermal analysis, and interconnect reliability.

## Technical Tools

- **HDL and digital design:** Verilog HDL, Xilinx Vivado
- **CMOS layout and verification:** Magic VLSI, IRSIM
- **Multiphysics simulation:** COMSOL Multiphysics
