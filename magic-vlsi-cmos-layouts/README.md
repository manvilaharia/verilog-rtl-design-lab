# CMOS Logic Gate Layouts

Designed basic CMOS logic gate layouts using Magic VLSI as part of VLSI Design Lab coursework at VIT Vellore.

## Gates Designed

- NOT
- NAND
- OR
- AND
- NOR
- XOR

## Verification

Performed Design Rule Check using Magic VLSI. The lab report records zero DRC violations.

Functional verification was carried out using IRSIM.

## Tools

Magic VLSI, IRSIM and SCMOS technology
