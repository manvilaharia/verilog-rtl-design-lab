# 4-bit Carry Look-Ahead Adder

Designed a 4-bit carry look-ahead adder using Verilog HDL as part of VLSI Design Lab coursework at VIT Vellore.

## Files

- `cla.v` contains the Verilog implementation
- `cla_tb.v` contains the testbench

## Design

The circuit uses generate and propagate signals to calculate the carry outputs and produce the 4-bit sum.

## Simulation

The design was simulated using Xilinx Vivado with two input test cases.

## Tools

Verilog HDL and Xilinx Vivado
